# 🌸 GirlDeck — Cyberdeck feito com um celular Android antigo

> “I’m just a girl building a cyberdeck.”

## 📖 Sobre o projeto

O **GirlDeck** é um projeto pessoal de construção de um cyberdeck utilizando um celular Samsung Galaxy A32 como núcleo principal do sistema.

O objetivo do projeto é:
- aprender hardware;
- estudar Linux e programação;
- explorar cultura maker;
- desenvolver habilidades em tecnologia;
- criar conteúdo para redes sociais;
- construir uma estética cyberpunk girlie/girly tech.

O projeto será desenvolvido do zero, incluindo:
- montagem da case;
- customização visual;
- instalação de ambiente Linux;
- integração de periféricos;
- organização de setup portátil.
